对话

直接和板子上的模型聊天。左侧是保存在设备上的历史会话，可以随时切换或删除；每条会话互相独立，也不影响 QQ 等通道的历史。

    人格设定

    这段文字作为设备的人格与自我认知，每次对话都会注入模型上下文。保存后立即生效，无需重启。留空则使用系统默认人格。

    人格描述（soul.md）

    建议写清三件事：你是谁、性格怎样、怎么说话。支持 Markdown，中英文都可以。

    长期记忆

    下面是模型跨会话记住的内容，每行一条。可以改某一行、删掉某一行，或在末尾加新的一行，保存后按行同步到设备。

    记忆内容

    单条建议不超过 80 个汉字，空行会被忽略。清空全部内容会删除所有记忆。

    自动记录

    开启后，模型会在对话里自己把持久事实（称呼、在做的项目、手上的设备、稳定偏好）写成记忆条目，来源标记为 auto；重复的事实由设备去重。关闭后只保留手动编辑。改动需重启生效。
