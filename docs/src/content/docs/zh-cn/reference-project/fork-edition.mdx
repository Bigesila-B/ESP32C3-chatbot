## 与官方版本的差异

定制版发布在 `feature/context-compaction`，固件基于官方 [`a4edfe5`](https://github.com/espressif/esp-claw/commit/a4edfe594a99407c8b4d5d70b93906bdd762b745)。官方已有 Skills、Lua、QQ 机器人、MCP 和模型图片输入，表中列的是本分支在这些能力上的改动。

| 功能 | 官方基线 | 定制版 |
| --- | --- | --- |
| 聊天帮助 | 各条指令有自己的帮助入口 | Web 新增「指令列表」，聊天可发 `/help`。两处展示已启用的指令、中文说明、日期、CPU 和内存使用情况、今日及本月 token 用量和局域网 IP。`/session` 和 `/llm` 的子菜单、状态、结果和参数提示也显示中文。 |
| 回复提示 | 默认路由会发送「🦞 ESP-Claw is snapping on it...」，工具过程通知由构建配置控制 | 新装使用的规则已移除固定提示。Web 可随时切换工具调用过程通知，默认关闭。 |
| MCP | 已有 MCP Client 和 Server 能力 | Web 新增「MCP 设置」，可保存一个默认服务地址、测试连接并把它用作聊天调用的默认地址。 |
| Skills | 已有 Skills 和 Lua 脚本 | Web 新增「技能列表」，显示设备已加载的 Skills 和不可用的依赖工具组。带 PSRAM 的 ESP32-S3 可选用 MicroPython 运行小型 Python 脚本。 |
| 网页图片 | 单文件上传接口上限为 512 KiB | 在线聊天和文件管理会在浏览器里压缩超限图片。优先保留尺寸和细节，传给设备的文件仍在上限以内。 |
| 网页加载 | 由设备发送固件内嵌的压缩网页 | 完整发送 gzip 资源，避免压缩文件末尾的字节被误删后导致网页加载失败。 |
| 会话记忆 | 会话文件达到大小阈值后压缩 | 增加「上下文窗口 (token)」设置和基于模型窗口的压缩阈值。压缩时优先保留最近的对话，并尝试生成较早内容的摘要。 |
| 存储写满 | 会话索引重建失败可中断本轮回复 | 在无法读取历史且索引重建失败时，尽量继续生成本轮回复。上传明确报告存储不足，释放空间后可恢复因写满中断的 Skill 激活。 |

截至 2026 年 11 月 14 日，官方 `master` 为 [`50072775`](https://github.com/espressif/esp-claw/commit/50072775cfa20d7ce25a9b27591d9d7c8b9dbab5)，已包含持久化 Web 聊天记录。定制版从较早基线构建，刷新 Web 聊天页会清空页面上的消息显示，设备上模型使用的会话记忆另行保存。

## 使用方法

- **指令和用量**。在网页打开「指令列表」，或在聊天里发 `/help`。Web 聊天用设备图标显示帮助标题。设备直接处理帮助命令，免用模型 token。统计以模型 API 返回的用量为准，按设备时区累计，从启用后开始记录。局域网设置页可通过显示的 IP 打开。
- **旧设备关闭固定提示**。升级会保留已有路由。若仍看到小龙虾提示，在设备串口控制台运行 `auto rules`，确认规则存在后运行 `auto delete_rule im_any_message_working_reply`。
- **显示或隐藏工具调用过程**。打开「系统设置 → 基本设置 → 聊天回复」，切换「显示工具调用过程」，点「保存本页」。保存后即时生效，工具本身仍可被模型调用。
- **连接 MCP**。打开「系统设置 → MCP 设置」，输入 ESP32 能访问的 HTTP(S) MCP 服务地址，测试后保存。在「Capabilities 管理」中为 LLM 启用 MCP Client，重启后可在聊天中调用工具。服务需提供 Streamable HTTP 端点。
- **查看和使用 Skills**。打开 Web 侧栏的「技能列表」。看到 `cap_micropython` 时，可在「在线聊天」发送「请用 cap_micropython 运行内置示例，把 count 设为 7 并返回结果」，示例的 sum 为 28。自定义 Skill 可在「文件管理」上传到同名目录 `/skills/<id>/`，上传后重启设备或在串口运行 `skill --register <id> --file <id>/SKILL.md`。
- **安装 Python Skill**。构建时在 `idf.py menuconfig` 打开 `App Claw Config → App Claw Capabilities → Enable MicroPython scripts for Skills`。在 Skill 的 `SKILL.md` 声明 `cap_micropython` 工具组，通过 `python_run_script` 运行 `{CUR_SKILL_DIR}/scripts/...`，用 `args` 接收 JSON 参数，用 `print()` 返回结果。
- **发送大图**。在 Web 聊天选图，压缩完成后发送。512 KiB 及以内的原样上传。超限图片先尝试保留原始尺寸，必要时降低 JPEG 质量或缩小图片。透明 PNG 若转成 JPEG 会用白底，压缩的动图只保留一帧。识图模型须支持设备上传的图片。
- **调整上下文窗口**。在「系统设置 → LLM 设置」填写模型的上下文窗口，使用 0 或留空可按模型名自动匹配。设备约在窗口的 60% 启动压缩，另有约 150 KiB 的会话文件阈值兜底。可用 `/session new` 新建会话，`/session list` 查看会话。

## ESP32-S3 实测范围

已用 16 MiB Flash、8 MiB PSRAM 的 ESP32-S3 验证帮助、token 计数、MCP 工具调用、自定义 Python Skill、网页大图上传和存储写满后的聊天回复。新版的中文子菜单和网页设置已通过本地构建与预览检查，待烧录后做真机回归。

本版开启 MicroPython 构建后，应用镜像为 3,008,112 字节，在实测硬件使用的 3,800 KiB 应用分区剩约 862 KiB。不同板型以构建输出和实际分区表为准。

MicroPython 是按需启用的嵌入式运行时，测试配置分配 256 KiB PSRAM 堆，支持部分内置模块和脚本目录内的导入。脚本单文件上限为 32 KiB，默认超时 1 秒，最大 5 秒，最多捕获 4,095 字节的输出。依赖桌面 Python 第三方库或系统命令的 Skills 需要适配，外设和网络操作可使用已有的 Lua 模块与工具。

存储写满时，新消息可能无法保存到历史。若 QQ 收到 `ESP_FAIL`，可先在「文件管理」查看剩余空间。此次验证覆盖存储写满触发的会话问题，实际 QQ 投递独立于这项修复。上下文摘要的长会话效果仍需持续验证。
